# Task 3: Data Preprocessing

## Overview
This task focuses on preprocessing the scraped articles dataset to prepare it for subsequent stages of the project.

## Project Files
- `preprocessing.py` — Python script for the preprocessing task.
- `articles_100000.csv` — article dataset associated with this task.
- `preprocessing_report.txt` — report containing preprocessing results.

## Requirements
- Python 3
- Required packages listed in the project's `requirements.txt`, if applicable.

## How to Run
From the project root, run:

```powershell
python "Task 3 (Preprocessing)/preprocessing.py"
```

Alternatively, open PowerShell inside the Task 3 folder and run:

```powershell
python preprocessing.py
```

## Output
Review `preprocessing_report.txt` and the generated CSV files for the results of preprocessing.

## Note
Confirm the exact input and output filenames in `preprocessing.py` before running the script.
