# Advanced Web Scraping with Python

A Python-based web scraping project for collecting article metadata from AI and technology news websites.

## Features
- Extract article titles and URLs
- Collect author names and publication dates when available
- Collect article time and source information
- Parse HTML using BeautifulSoup
- Use Requests and Selenium for web access
- Export scraped data to CSV

## Technologies
- Python
- Requests
- BeautifulSoup
- Selenium
- Pandas
- lxml
