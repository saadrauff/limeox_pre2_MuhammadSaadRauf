## 1. PROJECT INTRODUCTION

The Sobel Operator is an image processing technique used for edge detection.

It identifies boundaries and edges in images by calculating changes in pixel intensity in horizontal and vertical directions.

In this task, the Sobel Operator was applied to the CIFAR-10 image dataset.

The experiments included:
- Image loading and preprocessing.
- RGB to grayscale conversion.
- Sobel X edge detection.
- Sobel Y edge detection.
- Gradient magnitude calculation.
- Kernel size comparison.
- Stride comparison.
- Before and after image visualization.
- Processing time analysis.

**Important:** The original news classification dataset contains text, whereas Sobel is an image processing technique. Therefore, a separate image dataset was used for this task.

### Sobel X

Sobel X detects intensity changes in the horizontal direction and highlights corresponding vertical edges.

### Sobel Y

Sobel Y detects intensity changes in the vertical direction and highlights corresponding horizontal edges.

### Gradient Magnitude

Gradient magnitude combines Sobel X and Sobel Y to represent the overall edge strength.

Formula:

G = sqrt(Gx² + Gy²)

Where:

- Gx = Horizontal gradient
- Gy = Vertical gradient
- G = Gradient magnitude

## 5. EXPERIMENT 2 - KERNEL SIZE AND STRIDE COMPARISON

**Python file:** sobel_kernel_stride_comparison.py

This experiment was performed to investigate how different kernel sizes and stride values affect edge detection, output dimensions and processing time.

### Kernel Sizes Tested

1. 3 × 3
2. 5 × 5
3. 7 × 7

### Stride Values Tested

1. Stride 1
2. Stride 2
3. Stride 3

### Total Combinations

3 kernel sizes × 3 stride values = 9 combinations.

Images processed: 500.

Total image/configuration operations: 4,500.

### Processing Method

- RGB images were converted to grayscale.
- Sobel-style X and Y kernels were generated.
- PyTorch conv2d was used to apply convolution.
- Custom stride values were applied.
- Gradient magnitude was calculated.
- Results were normalized and saved.
- Before and after comparisons were generated.

Larger Sobel-style kernels were constructed using separable smoothing and derivative coefficients.

Unlike the initial OpenCV experiment, this implementation uses PyTorch to explicitly control convolution stride.

## 6. KERNEL SIZE AND STRIDE OUTPUT DIMENSIONS

Original image dimensions: 32 × 32.

Padding: 0 (No Padding).

### Output Dimensions

| Kernel Size | Stride 1 | Stride 2 | Stride 3 |
|---|---|---|---|
| 3 × 3 | 30 × 30 | 15 × 15 | 10 × 10 |
| 5 × 5 | 28 × 28 | 14 × 14 | 10 × 10 |
| 7 × 7 | 26 × 26 | 13 × 13 | 9 × 9 |

### Output Size Formula

Output = floor((Input - Kernel) / Stride) + 1

The output dimensions decrease when kernel size or stride increases.

Stride 1 preserves more spatial information, whereas stride 2 and stride 3 reduce output resolution.

## 9. IMPORTANT OBSERVATIONS

### Kernel Size

Kernel size determines the area of the image considered during convolution.

- 3×3: Smaller neighborhood and higher output resolution.
- 5×5: Larger neighborhood and lower output resolution.
- 7×7: Even larger neighborhood and lower output resolution.

### Stride

Stride determines how many pixels the convolution filter moves at each step.

- Stride 1: Moves one pixel at a time.
- Stride 2: Moves two pixels at a time.
- Stride 3: Moves three pixels at a time.

Increasing stride reduces the output dimensions.

### Before and After Comparison

Original images were compared with their processed outputs.

The visualizations show:

- Original RGB image.
- Grayscale image.
- Sobel X.
- Sobel Y.
- Gradient magnitude.

These comparisons demonstrate how edge information is extracted from original images.
